# Layouts — readme-viewer

Single-view desktop app shell. Three-row body grid (topbar / workspace / statusbar) with a
two-column workspace (optional sidebar + panes).

## AppShell — `index.html:13-146` + `styles.css:46-61`

The whole app is one document. Body is a 3-row grid; overflow is clipped so only the panes and
the sidebar scroll.

```html
<body>
  <header class="topbar">…</header>      <!-- see components.md: TopBar -->
  <div class="layout" id="layout" data-mode="split">…</div>
  <footer class="statusbar">…</footer>   <!-- see components.md: StatusBar -->
  …
</body>
```

```css
html, body { height: 100%; }

body {
  margin: 0;
  display: grid;
  grid-template-rows: auto 1fr auto;
  background: var(--bg);
  color: var(--fg);
  font-family: var(--sans);
  font-size: 14px;
  overflow: hidden;
}

button, input, textarea { font-family: inherit; font-size: inherit; color: inherit; }

:focus-visible { outline: 2px solid var(--accent); outline-offset: 1px; }
```

## Workspace grid — `index.html:60-106`, `styles.css:138-208`

```html
<div class="layout" id="layout" data-mode="split">

  <aside class="sidebar" id="sidebar" hidden>
    <div class="sidebar-head">فهرست مطالب</div>
    <nav class="toc" id="toc" aria-label="فهرست مطالب"></nav>
    <div class="sidebar-foot">
      <label for="baseUrl">آدرس پایه لینک‌های نسبی</label>
      <input type="text" id="baseUrl" dir="ltr" spellcheck="false"
             placeholder="https://github.com/user/repo/blob/main/">
    </div>
  </aside>

  <main class="panes" id="panes">
    <section class="pane pane-editor" id="paneEditor">…</section>
    <div class="resizer" id="resizer" role="separator" aria-orientation="vertical" tabindex="0"
         title="برای تغییر عرض بکشید"></div>
    <section class="pane pane-preview" id="panePreview">…</section>
  </main>
</div>
```

```css
.layout {
  display: grid;
  grid-template-columns: auto minmax(0, 1fr);
  min-height: 0;
}

.layout[data-sidebar="off"] { grid-template-columns: minmax(0, 1fr); }
.layout[data-sidebar="off"] .sidebar { display: none; }

.panes {
  display: grid;
  grid-template-columns: var(--split) 7px minmax(0, 1fr);
  min-height: 0;
  min-width: 0;
}

.panes[data-mode="write"] { grid-template-columns: minmax(0, 1fr) 0 0; }
.panes[data-mode="write"] .pane-preview, .panes[data-mode="write"] .resizer { display: none; }
.panes[data-mode="preview"] { grid-template-columns: 0 0 minmax(0, 1fr); }
.panes[data-mode="preview"] .pane-editor, .panes[data-mode="preview"] .resizer { display: none; }
```

State is driven entirely by three data attributes: `body[data-theme]`, `.layout[data-sidebar]`,
`.panes[data-mode]`, plus `--split` for the editor/preview ratio (set by the resizer).

## Narrow-screen layout — `styles.css:458-465`

Below 780px the panes stack vertically and the sidebar becomes an overlay drawer.

```css
@media (max-width: 780px) {
  .panes { grid-template-columns: minmax(0, 1fr) !important; grid-template-rows: 1fr 7px 1fr; }
  .pane { grid-column: 1; }
  .resizer { cursor: row-resize; }
  .sidebar { position: fixed; inset-block: var(--topbar-h) 0; inset-inline-end: 0; z-index: 20; box-shadow: var(--shadow); }
}
```

## Vendor CSS layers loaded on top of the shell

```html
<link rel="stylesheet" href="vendor/github-markdown-light.css" id="ghLight">
<link rel="stylesheet" href="vendor/github-markdown-dark.css" id="ghDark">
<link rel="stylesheet" href="vendor/hljs-github.min.css" id="hljsLight">
<link rel="stylesheet" href="vendor/hljs-github-dark.min.css" id="hljsDark">
<link rel="stylesheet" href="styles.css">
```

`github-markdown.css` supplies the `.markdown-body` typography (GitHub Primer look);
`hljs-github*.css` supply code token colors. Light/dark variants are swapped at runtime by
toggling `disabled` on those `<link>` tags from `app.js`.
